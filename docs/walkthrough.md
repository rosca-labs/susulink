# SusuLink Project Walkthrough

Welcome to **SusuLink** — a production-grade ROSCA platform built on Stellar. This document guides you through the project's structure and core features.

## 📁 Project Structure

```text
susulink/
├── contracts/        # Soroban smart contracts (Rust)
├── backend/          # Node.js/Express API & Prisma
├── frontend/         # Next.js 16 / React 19 dApp
├── docs/             # Architecture & contract docs
└── scripts/          # Deployment & automation
```

## 🚀 Key Features

1. **Trustless Circles**: On-chain rotation and payout logic.
2. **USDC Integration**: Contributions and payouts using Stellar USDC.
3. **SEP-10 Auth**: Secure wallet-based authentication.
4. **Premium UI**: High-fidelity dashboard for managing circles.
